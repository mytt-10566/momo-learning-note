
## mac
### .env配置

#### PROFILE_ARN
终端执行：open "$HOME/Library/Application Support/Kiro/User/globalStorage/kiro.kiroagent"
找到profile.json，arn对应值就是PROFILE_ARN


配置：
```bash

KIRO_CREDS_FILE="/Users/xxx/.aws/sso/cache/kiro-auth-token.json"

PROXY_API_KEY="xxxx"

PROFILE_ARN="arn:aws:xxx"
```


启动：
```bash
cd 

python3 main.py
```
