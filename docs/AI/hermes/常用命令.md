进入对话界面：
> hermes

会话：sessions

| 子命令    | 描述                                              | 备注 |
|--------|-------------------------------------------------|----|
| list   | List recent sessions                            |    |
| browse | Interactive picker — browse, search, and resume |    |
| export | Export to JSONL                                 |    |
| rename | Set or change a session's title                 |    |
| delete | Delete a specific session                       |    |
| prune  | Delete old sessions                             |    |
| stats  | Show session store statistics                   |    |

示例：

```bash
## 查看会话列表
hermes sessions list

Title                            Preview                                  Last Active   ID
     ──────────────────────────────────────────────────────────────────────────────────────────────────────────────
     Hermes sessions command refere   hermes sessions                          9m ago        20260607_114227_dd2cb1
     —                                我有个网页，该网页上有基金的定期报告，我期望下载这些报告，并将文件名修改为表   2026-05-24    20260524_095003_761f8a
     —                                查看今天天气                                   2026-05-24    20260524_014416_9dd788

## 重新命名
hermes sessions rename 20260524_095003_761f8a "基金定期报告抓取"

```

新打开一个终端页面，恢复之前的会话
> hermes --resume 20260524_095003_761f8a
